# WhatsApp Bot Template

Template Node.js para criação de bots utilizando WhatsApp Web.

## Objetivo

Fornecer uma base simples e reutilizável para projetos que precisam:

- autenticar no WhatsApp por QR Code;
- manter sessão persistente;
- identificar grupos;
- enviar mensagens;
- enviar imagens;
- enviar documentos e PDFs;
- executar continuamente com PM2.

## Tecnologias

- Node.js
- whatsapp-web.js
- Puppeteer
- qrcode-terminal
- dotenv
- PM2
